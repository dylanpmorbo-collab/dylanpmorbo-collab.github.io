AQUELLO QUE NOS RODEA — WEB CMS v2
====================================

ADMINISTRACIÓN DE CONTENIDOS
----------------------------
La web se administra con Pages CMS:

    https://app.pagescms.org/dylanpmorbo-collab/dylanpmorbo-collab.github.io/main

Pages CMS utiliza el archivo .pages.yml situado en la raíz del repositorio.
Desde ese panel se pueden gestionar relatos, microrrelatos, expedientes,
personajes, documentos navegables, imágenes y la configuración del sitio.

PUBLICACIÓN
-----------
Los cambios guardados desde Pages CMS se escriben en la rama main de GitHub.
La acción «Publicar Aquello que nos Rodea» construye automáticamente la web y
la publica en GitHub Pages:

    https://dylanpmorbo-collab.github.io/

La fuente editable se encuentra en:
    Aquello_que_nos_Rodea_WEB_CMS_v2/content/
    Aquello_que_nos_Rodea_WEB_CMS_v2/assets/

El generador está en:
    Aquello_que_nos_Rodea_WEB_CMS_v2/scripts/build.js

IMPORTANTE
----------
No es necesario editar manualmente el HTML generado para publicar contenido.
La carpeta dist/ se reconstruye automáticamente durante cada publicación.

No borres ni renombres campos de .pages.yml sin actualizar también build.js.
No edites archivos dentro de assets/uploads desde fuera de Pages CMS salvo que
sepas qué contenido los referencia.
